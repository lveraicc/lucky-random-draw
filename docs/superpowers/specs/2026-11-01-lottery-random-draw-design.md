# 双色球与大乐透随机摇号机设计

日期：2026-11-01  
状态：待用户复核  
工作标题：随机一注

## 1. 产品目标

制作一个纯前端网页，用老虎机式的联排转轮随机生成一组双色球或大乐透号码。产品定位是随机模拟与娱乐工具，不是官方开奖平台，也不提供购彩、兑奖或中奖预测能力。

### 1.1 成功标准

- 用户可在双色球和大乐透之间切换。
- 每次点击只生成一组号码。
- 生成的号码严格符合对应玩法的数量、范围和去重规则。
- 转轮动画具有实体机械感，并逐列揭晓预先确定的随机结果。
- 桌面和手机均可完整操作，不需要横向滚动。
- 最近记录、静音设置可在刷新后保留。
- 页面明确说明“随机模拟，仅供娱乐”。

### 1.2 非目标

- 不接入手动选号或自选号码编辑。
- 不接入真实购彩、支付、兑奖或开奖数据。
- 不提供中奖判断、号码推荐或开奖预测。
- 不建设账号、云端同步、排行榜或服务端接口。
- 首版不支持一次批量生成多组号码。

## 2. 玩法规则

| 玩法 | 主号码 | 特别号码 | 展示顺序 |
| --- | --- | --- | --- |
| 双色球 | 从 1–33 中选择 6 个红球 | 从 1–16 中选择 1 个蓝球 | 红球升序，最后展示蓝球 |
| 大乐透 | 从前区 1–35 中选择 5 个前区号码 | 从后区 1–12 中选择 2 个后区号码 | 前区升序，后区升序 |

每组号码内部不得重复。用户可以切换玩法，但每次点击只生成当前玩法的一组结果。

## 3. 视觉设计

采用用户确认的“经典演播厅”方向：

- 深海军蓝至黑色的舞台背景，顶部有柔和金色聚光。
- 机器使用深色金属外壳、黄铜描边、暖色状态灯和玻璃转轮窗口。
- 页面气质偏节目演播厅与实体机械，不使用赌场金币、夸张大奖或廉价霓虹效果。
- 红球使用暖红/铜色，蓝球使用冷蓝/玻璃色；同时保留明确的文字标签，不能只依赖颜色区分。
- 品牌文字、按钮和辅助信息使用清晰的无衬线字体；标题可少量使用衬线字体强化仪式感。

### 3.1 首屏布局

采用用户确认的“沉浸单舞台”：

- 顶部：工作标题、双色球/大乐透切换、静音控制。
- 中央：聚光灯下的摇号机。桌面最大宽度约 960px，以机器为唯一视觉主角。
- 机器下方：主要摇号按钮。
- 首屏底部：最近 3 组记录摘要及“查看全部”入口。
- 页脚：固定的“随机模拟 · 仅供娱乐，不代表官方开奖”说明。

历史抽屉打开后显示最多 20 组记录。手机端按单列排列，最近记录通过底部抽屉展开，不产生横向滚动。

## 4. 核心交互与动画

### 4.1 初始状态

- 默认玩法为双色球。
- 当前玩法已有历史时，机器静态显示该玩法最近一组结果；没有历史时显示 `--` 占位转轮。
- 切换玩法时按同一规则显示该玩法最近结果或占位状态，不自动播放动画。
- “开始摇号”是主操作。

### 4.2 摇号流程

1. 用户点击“开始摇号”或按空格键。
2. 应用先使用安全随机算法生成完整且最终的结果。
3. 转轮开始转动，所有交互控件进入锁定状态。
4. 主号码转轮错峰减速并依次停止。
5. 特别号码最后停止，以一次干净的金属锁定音收尾。
6. 页面展示“再来一组”和“复制号码”，并将结果写入历史。
7. 历史记录区立即显示最新结果。

标准动画约 3.2 秒。转轮先加速，再保持高速转动，主号码依次停止，特别号码最后落定。用户可以关闭音效，也可以开启“减少动态效果”；后者跳过高速滚动，以 300–500 毫秒淡入或直接揭晓。

### 4.3 转轮设计

- 双色球显示 6 个主转轮和 1 个特别转轮。
- 大乐透显示 5 个主转轮和 2 个特别转轮。
- 动画只负责揭晓已生成的结果，不能重新决定最终号码。
- 快速连点不得产生第二组号码。
- 摇号期间禁用玩法切换；摇号结束后恢复。
- 页面进入后台再返回时，跳过未完成动画并显示已生成结果。

### 4.4 音效

使用本地轻量原创音效，避免远程文件和版权素材：

- 机械低鸣：转轮转动时循环播放。
- 棘轮咔哒：声音间隔随减速逐渐拉长。
- 锁定音：最终号码落位时播放一次。
- 不加入赌场音乐、金币雨、欢呼或“大奖”提示音。

音效默认开启，但只在用户主动点击摇号后播放。界面提供显眼的一键静音，音效偏好保存在本地。移动设备可提供轻震动作为可选反馈，并允许关闭。

### 4.5 结果操作

- “再来一组”重新生成并播放一组号码。
- “复制号码”复制格式化的完整结果，例如“双色球：红球 03 12 21 28 31 33，蓝球 09”。
- 大乐透使用对应格式，例如“大乐透：前区 02 11 18 27 34，后区 04 09”。
- 复制成功或失败都提供短暂、可读的反馈。

不引入 Framer Motion 或其他重型动画库。应用构建为纯静态站点，运行时不依赖后端服务或远程随机接口。

### 5.3 组件职责

- `GameSwitcher`：切换玩法并读取当前玩法配置。
- `LotteryMachine`：编排转轮、聚光灯和最终落位。
- `Reel`：展示单个转轮及其转动、减速、停止状态。
- `DrawControls`：摇号、再来一组、复制和静音。
- `HistoryPanel`：最近记录摘要及完整历史抽屉。
- `Disclaimer`：展示非官方与娱乐用途说明。

## 6. 随机算法

不得使用 `Math.random()` 生成最终号码。应用必须使用 `crypto.getRandomValues()`：

1. 生成 32 位无符号随机整数。
2. 使用拒绝采样消除取模偏差：若随机值大于等于 `floor(2^32 / range) * range`，则重新生成。
3. 将无偏随机整数映射到目标号码范围。
4. 使用 Fisher–Yates 洗牌选取号码。
5. 对主号码和特别号码分别去重、排序。
6. 将结果锁定为本次摇号的唯一数据源，再交给动画展示。

浏览器不支持安全随机数时，停止本次摇号并显示明确错误，不降级到不可靠的随机源。

## 7. 状态与数据模型

### 7.1 状态机

```text
idle -> drawing -> revealing -> complete
```

- `idle`：可切换玩法或开始摇号。
- `drawing`：结果已生成，转轮高速转动，操作锁定。
- `revealing`：转轮依次停止。
- `complete`：结果完整展示，可复制或再次摇号。

异常中断时，只允许进入可恢复状态；最终结果以生成时锁定的数据为准。

### 7.2 核心类型

```ts
type GameId = "ssq" | "dlt";

interface LotteryResult {
  id: string;
  game: GameId;
  primary: number[];
  special: number[];
  createdAt: string;
}

interface GameConfig {
  id: GameId;
  name: string;
  primaryCount: number;
  primaryMin: number;
  primaryMax: number;
  specialCount: number;
  specialMin: number;
  specialMax: number;
}
```

玩法配置由独立常量表提供，界面和随机算法不得硬编码两套重复规则。

### 7.3 本地数据

- 历史记录最多保留 20 组，新的在前。
- 每条记录包含玩法、主号码、特别号码和时间。
- 使用带版本号的 `localStorage` 键，避免未来结构升级时误读旧数据。
- 音效开关和减少动态效果偏好独立保存。
- “减少动态效果”首次进入时读取系统的 `prefers-reduced-motion`，此后允许用户在应用内覆盖并记住选择。
- 不收集、不上传用户数据。

## 8. 异常处理与无障碍

- `localStorage` 不可用时，本次摇号保持可用，历史暂存在内存中，并提示刷新后可能丢失。
- 音效播放被浏览器阻止时自动保持静音，不阻断摇号。
- 复制 API 不可用时给出失败提示，结果仍可读取。
- 页面切到后台后返回时，取消残留动画计时器并显示最终结果。
- 组件卸载或玩法切换时清理动画监听和定时器，避免旧结果覆盖新状态。
- 用户启用 `prefers-reduced-motion` 时减少或跳过高速旋转。
- 空格键和 Enter 均可触发主要操作，焦点样式清晰。
- 结果区域使用 `aria-live` 播报完整号码与玩法。
- 所有按钮提供可读标签，触控目标至少 44px 高。
- 红/蓝区和前/后区同时显示文字标签，不只使用颜色。
- 动画期间的操作锁定状态可被辅助技术识别。

## 9. 测试与验收

### 9.1 单元测试

- 双色球始终生成 6 个不重复红球和 1 个不重复蓝球，范围与排序正确。
- 大乐透始终生成 5 个不重复前区号码和 2 个不重复后区号码，范围与排序正确。
- 大样本测试检查结果没有越界、重复或数量异常。
- 模拟随机源边界值，验证拒绝采样不产生越界。
- 损坏或版本不匹配的历史数据会被安全忽略。

### 9.2 组件测试

- 摇号期间按钮和玩法切换被禁用，快速点击只产生一组结果。
- 完整流程可进入结果状态并显示复制操作。
- 静音和减少动态效果偏好能够保存。
- 历史达到上限时删除最旧记录。
- 无障碍名称和结果播报内容正确。

### 9.3 浏览器验收

- 使用 Playwright 分别完成双色球和大乐透各一次完整摇号。
- 刷新页面后历史仍存在。
- 1440×900 桌面视口无内容截断。
- 390×844 手机视口无横向滚动，按钮无遮挡。
- 键盘可以完成摇号和再次摇号。
- 减少动态效果模式下不播放高速转轮。
- 生产构建成功，浏览器控制台无未处理错误。
