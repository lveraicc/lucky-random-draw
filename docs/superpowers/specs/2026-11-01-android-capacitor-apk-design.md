# 随机一注 Android APK 设计规格

日期：2026-11-01  
状态：待用户复核  
目标平台：Android

## 1. 目标

把现有 React 网页封装为可独立安装、可分享给朋友的 Capacitor Android 应用。

### 1.1 成功标准

- 生成一个已签名的 Release APK。
- 应用无需联网即可使用双色球和大乐透随机摇号。
- 不依赖 `localhost`、GitHub Pages 或任何后端服务。
- 安装后具有独立应用图标和名称“随机一注”。
- 手机端布局、音效、复制、历史记录和减弱动效与网页版一致。
- APK 可与朋友分享并通过安卓系统“未知来源”安装。
- 使用相同包名和签名密钥即可发布后续升级版本。

### 1.2 非目标

- 不发布到 Google Play。
- 不生成 AAB。
- 不实现自动在线更新。
- 不增加账号、云同步、广告、统计或推送。
- 不申请相机、定位、通讯录或存储文件等运行时敏感权限。

## 2. 应用身份

| 项目 | 值 |
| --- | --- |
| 应用名称 | 随机一注 |
| Android 包名 | `com.lveraicc.luckyrandomdraw` |
| 版本名称 | `1.0.0` |
| 初始版本代码 | `1` |
| 主显示方向 | 竖屏优先，同时支持横屏自适应 |
| 最低 Android 版本 | 跟随所采用 Capacitor 版本的官方最低要求，预计 Android 7+ |
| 应用类型 | 本地 WebView 封装 |

包名和签名密钥一经发布应保持固定，否则 Android 不会将其识别为同一应用的升级。

## 3. 技术架构

### 3.1 Capacitor

- 使用 Capacitor 生成原生 Android 工程。
- Vite 构建后的 `dist/` 作为本地静态资源同步到 Android 工程。
- Android WebView 从应用包内加载页面，不访问开发服务器。
- `vite.config.ts` 使用相对资源路径，保证 Android 和静态托管均可加载。
- JavaScript、CSS、字体、图标和音效全部随 APK 分发。

### 3.2 原生能力

- 使用 `@capacitor/app` 处理 Android 返回键：
  - 历史记录抽屉打开时，返回键只关闭抽屉。
  - 抽屉未打开时，返回键退出应用。
- 状态栏和导航栏使用深色主题。
- 使用 `viewport-fit=cover` 与 CSS 安全区域变量处理刘海屏、圆角和底部手势区域。
- Web Audio 仍在用户主动点击摇号后播放。
- 复制优先使用 WebView Clipboard API，失败时继续使用现有本地回退逻辑。

### 3.3 视觉资源

- 应用图标延续深色舞台和暖金色视觉，使用“L”标识。
- 使用 Android 自适应图标。
- 启动画面使用深色背景、暖金色标志和“随机一注”名称。
- 图标和启动画面由本地矢量源生成，不依赖远程图片服务。

## 4. 构建环境

本机当前只有 Java 8，且没有 Android SDK。实现时在项目外补齐本地工具：

- 便携式 Java 21。
- Android SDK Command-line Tools。
- Android Platform、Build Tools 和 Platform Tools。
- Capacitor Android Gradle Wrapper。

工具和环境变量尽量放在项目外，避免把二进制工具提交到 GitHub。构建命令必须显式使用 Java 21 和本地 Android SDK。

## 5. 打包与签名

### 5.1 Release APK

- 生成 Release 签名 APK，不使用调试签名作为最终交付物。
- 输出文件命名为 `随机一注-1.0.0.apk`。
- 最终 APK 复制到 Windows 桌面，方便发送。
- APK 不提交到公开 GitHub 仓库。

### 5.2 签名密钥

- 生成独立的 Android Release Keystore。
- 密钥保存在 `C:\Users\22360\.android\`。
- 密码保存在项目外的本机私密文件，并限制为当前 Windows 用户可读。
- `keystore.properties`、Keystore、密码和 APK 均加入忽略规则。
- 用户必须备份 Keystore 与密码；丢失后无法为同一包名生成可覆盖升级的新版 APK。

### 5.3 权限

- 保留 Capacitor Android WebView 所需的清单级 `INTERNET` 权限。
- 应用不调用任何外部网络接口，不加载远程图片、字体、音频或 CDN 资源。
- 该清单权限不会向用户弹出授权窗口；仍禁用明文网络流量。
- 不申请定位、相机、麦克风、通讯录、短信或外部文件权限。
- 数据仅保存在当前应用的 WebView 本地存储中。

## 6. 数据与生命周期

- 最近 20 组历史和偏好继续使用带版本号的 `localStorage`。
- 升级 APK 时，只要包名与签名密钥不变，历史和偏好会保留。
- 卸载应用会清除本地历史和偏好。
- 页面进入后台返回时继续使用现有跳过动画并展示锁定结果的逻辑。
- 无网络时随机数仍然由设备 Web Crypto 生成。

## 7. 异常处理

- 设备不支持安全随机数时显示明确错误，不降级到弱随机源。
- WebView 本地存储不可用时仍允许摇号，并提示刷新或重启后可能丢失。
- 原生返回键监听不可用时不影响页面基本操作。
- 签名或 Gradle 构建失败时保留现有网页代码，不覆盖旧 APK。
- 复制 API 失败时显示失败提示，应用不崩溃。

## 8. 安全与合规

- 页面继续明确展示“随机模拟 · 仅供娱乐，不代表官方开奖”。
- 不包含真实购彩、支付、兑奖或中奖预测功能。
- 不收集、上传或共享任何用户数据。
- 不将密钥、密码、签名材料或构建产物提交到 GitHub。

真机安装与操作需要用户完成；发现问题后再进入修复流程。
